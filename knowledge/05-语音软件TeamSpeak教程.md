## ST 战队 TS 地址是什么
<!-- rag: aliases=语音门牌|TS门牌|战队语音地址; scope=ST战队; exact=true -->

ST 战队的 TeamSpeak 3 语音服务器地址是：`GPFWD.ts5.plus`。

群里问“TS 网址是什么”、“TS 地址”、“ST 战队 TS”、“语音地址”或“TS 服务器”时，通常指的都是这个连接地址，不是 TeamSpeak 官网。打开 TeamSpeak 3，在“连接服务器”中输入 `GPFWD.ts5.plus` 即可。

## TeamSpeak 3 安装包和汉化包在哪里下载

TeamSpeak 3 的本体安装包和汉化包都在 QQ 群文件里，可以直接从群文件下载，不用另外去找官网安装包。两个文件放在群文件的相同目录中。

安装顺序：
- 先下载并安装 TeamSpeak 3 本体。
- 安装完成后打开一次 TeamSpeak 3，再把软件关闭。
- 然后双击安装群文件里的汉化包。
- 重新打开 TeamSpeak 3，确认界面已经汉化。

## TS3 怎么连接服务器

如果服务器要求使用 TeamSpeak 3 语音，先安装并打开 TeamSpeak 3。

本体安装包和汉化包都可以在 QQ 群文件的相同目录下载。先安装本体，打开并关闭一次软件，再双击安装汉化包，即可完成汉化。

连接步骤：
- 打开 TeamSpeak 3。
- 点击顶部菜单“连接”。
- 选择“连接服务器”。
- 在服务器地址里输入：`GPFWD.ts5.plus`
- 在名称/昵称里输入自己的游戏 ID。
- 点击连接。

注意：昵称建议和游戏内 ID 保持一致，方便管理和队友识别。

## TS3 怎么添加书签

第一次连上语音服务器后，建议把服务器添加到书签，之后可以快速进入。

操作步骤：
- 连上服务器后，点击顶部菜单“书签”。
- 选择“添加到书签”。
- 确认书签名称、昵称、服务器地址。
- 点击 OK 保存。
- 下次进入时直接点“书签”，选择已保存的服务器即可。

## TS3 语音输入怎么设置

进入服务器后，如果别人听不到你说话，优先检查 TeamSpeak 3 的音频输入设置。

设置路径：
- 点击“工具”。
- 进入“设置”。
- 找到“音频输入”。
- 语音通话模式选择“按键通话”。
- 点击“未分配快捷键”，设置一个自己熟悉、不影响游戏操作的按键。可以设置为T键、N键。

建议使用按键通话，不建议一直开麦。一直开麦容易把键盘声、环境声、回声带进频道，影响队友听指挥。

## TS3 声音太大或提示音太吵怎么办

如果 TeamSpeak 3 的提示音或音效包声音太大，可以调低音频输出里的音效包音量。

设置路径：
- 点击“工具”。
- 进入“设置”。
- 找到“音频输出”。
- 将“音效包音量”调低。
- 保存设置。
- 同时，右键某个具体的人，可以去调节对应的人的音量。

如果听不见队友，也检查系统输出设备、TS3 输出设备和耳机音量。

## TS3 常见问题

进不去语音服务器时，先检查：
- 服务器地址是否输入正确：`GPFWD.ts5.plus`
- 自己的网络是否正常。
- TeamSpeak 3 是否被防火墙拦截。
- 昵称是否填写为游戏 ID。
- 是否进入了正确频道。

别人听不到你时，先检查：
- 麦克风设备是否选对。
- 是否设置了按键通话。
- 按键通话快捷键是否真的按下。
- 系统麦克风权限是否开启。
- 麦克风是否被其他软件占用。

能进频道但听不到别人时，先检查：
- TeamSpeak 3 的音频输出设备。
- 系统默认输出设备。
- 耳机或音箱音量。
- 是否误开静音。

## 别人听不到我说话怎么办

别人听不到你说话，通常是麦克风设备、按键通话或系统权限的问题。

排查顺序：
- 先确认 TeamSpeak 3 的“音频输入”设备选的是正在使用的麦克风。
- 确认已经设置“按键通话”，并且说话时真的按住了快捷键。
- 在 TeamSpeak 3 的音频输入页面使用测试功能，看麦克风是否有输入。
- 检查 Windows 系统麦克风权限是否允许 TeamSpeak 3 使用。
- 检查麦克风有没有被 QQ、Discord、直播软件或其他程序占用。

如果以上都正常，但队友仍然听不到，可以重新插拔麦克风、重启 TeamSpeak 3，或者重新进语音频道。

## 听不到别人说话怎么办

听不到别人说话，优先检查输出设备和音量。

排查顺序：
- 确认 TeamSpeak 3 的“音频输出”设备选的是耳机或正确音箱。
- 检查系统默认输出设备。
- 检查耳机、系统音量和 TeamSpeak 3 音量。
- 看自己是否误开了静音或屏蔽。
- 如果只有提示音很吵，可以在“音频输出”里调低“音效包音量”。
