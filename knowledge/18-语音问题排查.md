# 语音问题排查

来源：
- 用户提供的语音问题排查文档
- 05-语音软件TeamSpeak教程.md 中的设置说明

遇到语音问题时，按顺序排查，每一步检查完再试一次。解决不了可以重复操作或跳到下一步。群里问问题时最好附上截图，很多时候光靠描述说不清楚。

## TS 麦克风没声音怎么办

这是最常见的 TS 语音问题，通常和输入设备、激活模式或蓝牙耳机有关。

排查顺序：
- 打开 TS3 → 工具 → 设置 → 音频输入。
- 检查"配置文件"是否选的是 Default。
- 检查"音频输入设备"是否为你正在使用的麦克风。
- 检查"激活模式"是否选的是"按键通话"。如果不是，改成按键通话。
- 检查"按键通话快捷键"是否已设置（可以改成鼠标侧键，不影响游戏操作）。
- 设置完后点"开始测试"，对着麦克风说话，看有没有绿色指示条跳动。

如果以上都正常但还是没声音：
- 检查是不是蓝牙耳机。蓝牙耳机的麦克风和音频输出会冲突（蓝牙协议限制），TS 可能检测不到蓝牙麦克风。解决方法是禁用蓝牙耳机的麦克风，改用其他麦克风（比如头戴有线耳机的麦、独立 USB 麦）。
- 检查声卡上是否有静音按钮，有些外置声卡或耳机线控上有物理静音键。
- 检查 Windows 系统麦克风权限：设置 → 隐私和安全性 → 麦克风，确认 TS3 有权限使用麦克风。

## TS 耳机没声音怎么办

别人说话你听不到，通常是输出设备选错了。

排查顺序：
- 打开 TS3 → 工具 → 设置 → 音频输出。
- 检查"配置文件"是否选的是 Default。
- 检查"音频输出设备"是否为你正在使用的耳机或音箱。
- 检查系统音量和 TS3 音量是否被静音或调太低。
- 检查耳机本身是否有物理音量旋钮或静音开关。

如果还是听不到：
- 检查 Windows 系统默认输出设备：右键任务栏音量图标 → 声音设置 → 输出，确认选的是你的耳机。
- 检查"音效包音量"是否太高盖过了人声，可以调低。

## TS 显示被禁麦怎么办

如果 TS3 界面显示麦克风被禁用（红色图标），通常是权限问题。

解决方法：
- 完全退出 TS3（右下角托盘也要退）。
- 右键 TS3 快捷方式 → 以管理员身份运行。
- 重新连接服务器测试。

如果管理员启动后仍然被禁麦，检查是否有其他软件（比如直播软件、录音软件）占用了麦克风。

## 用 TS 时游戏没声音怎么办

有些玩家同时开 TS3 和 Squad 时，游戏声音突然没了，通常是 Windows 音频设置冲突。

解决方法：
- 打开 Windows 设置 → 系统 → 声音 → 更多声音设置。
- 找到你的耳机和麦克风，右键 → 属性 → 高级。
- 把"独占模式"相关的选项全部关掉，点应用。
- 重启游戏和 TS3 测试。

## 游戏里没声音或不能用游戏麦怎么办

Squad 游戏内语音和 TS 是独立的两套系统。如果游戏内语音有问题，排查顺序：

第一步：检查游戏内音频设置
- 游戏中按 Esc → 右上角齿轮图标 → 音频。
- 把"音频输入"和"音频输出"都改成你正在使用的耳机和麦克风。
- 不要选 Default，直接选具体设备名。

第二步：检查 Windows 空间音效
- Windows 设置 → 系统 → 声音 → 你的耳机。
- 如果有"空间音效"或"音频增强"，全部关掉。这些功能会干扰 Squad 的音频系统。

第三步：检查音量合成器
- 右键任务栏音量图标 → 打开音量合成器。
- 找到 Squad，确认输出设备和输入设备都是你的耳机和麦克风。

第四步：检查系统麦克风权限
- Windows 设置 → 隐私和安全性 → 麦克风。
- 找到 Squad，确认已授予麦克风使用权限。

如果以上都试过还是不行，重启游戏。Squad 有时候启动时会检测不到新接入的音频设备，重启后通常能解决。

## TS 有声音但游戏内语音异常怎么办

有时候 TS3 语音正常，但 Squad 游戏内语音出问题：听不到队友说话、队友听不到你说话、或者左下角的麦克风图标不显示。这通常是 Squad 的语音模块卡住了，不是你的设备问题。

解决方法：
- 打开部署界面（按 Enter 或 Esc）。
- 在队伍列表里找到任意一个队友，右键点击他的名字。
- 选择"屏蔽麦克风"（Mute）。
- 等几秒钟，再右键同一个人，取消屏蔽。
- 回到游戏，检查语音是否恢复正常、麦克风图标是否重新出现。

这个操作相当于强制刷新 Squad 的语音系统。如果一次不行，可以多试几次，或者换一个队友重复操作。

如果仍然无效，尝试：
- 按 Esc → 设置 → 音频，重新选择一次输入和输出设备（即使没改也要重新点一下确认）。
- 退出服务器重新进入。
- 重启游戏。

## 排查问题时怎么问群里帮忙

群里大佬帮忙是自愿的，问问题时尽量说清楚：
- 描述你遇到的现象（"TS 麦克风没声音"还是"游戏里听不到队友"）。
- 说明你已经排查过哪些步骤。
- 附上截图，尤其是 TS3 的音频设置页面、Windows 声音设置页面。
- 如果需要远程协助，可以加好友用 QQ 远程控制。
